# Keyboard Shortcuts

## Main window

| Keys | Action |
|---|---|
| <kbd>Ctrl+O</kbd> | Import compositions from a spreadsheet |
| <kbd>Ctrl+Shift+C</kbd> | Copy table (all filtered rows, visible columns) |
| <kbd>Ctrl+Z</kbd>, <kbd>Ctrl+Y</kbd> | Undo, Redo |
| <kbd>Ctrl+B</kbd> | Show or hide the top panels |
| <kbd>F11</kbd> | Full screen on or off |
| <kbd>F10</kbd> | Move to the title bar menus |
| <kbd>Alt+F</kbd>, <kbd>Alt+E</kbd>, <kbd>Alt+V</kbd>, <kbd>Alt+H</kbd> | Open the File, Edit, View or Help menu |
| <kbd>Ctrl+Shift+E</kbd> | Expand analysis / Back to calculation |
| <kbd>Ctrl+C</kbd> | Copy text selected in a table cell |
| <kbd>Ctrl+Enter</kbd> (expression field) | Parse the composition expression |
| <kbd>F1</kbd> | Help — Documentation Home |
| <kbd>Ctrl+Q</kbd> | Exit |
| Arrow keys, <kbd>Space</kbd> or <kbd>Enter</kbd> | Move between periodic-table tiles and select or deselect an element |
| <kbd>Tab</kbd>, <kbd>Shift+Tab</kbd> | Move between controls |
| <kbd>Enter</kbd> (page field) | Go to the typed page; <kbd>Esc</kbd> restores the current page |

## Composition setup

| Keys | Action |
|---|---|
| <kbd>Enter</kbd> (amount, Single composition) | Commit the value and move to the field below in the same column |
| <kbd>Up</kbd>, <kbd>Down</kbd> (amount or range field) | Move to the field above or below in the same column |
| <kbd>Enter</kbd> (Min, Max or Step, Composition space) | Move to the next field: Min, Max, Step, then the next row |
| <kbd>Ctrl+Left</kbd>, <kbd>Ctrl+Right</kbd> (Composition space) | Move between Min, Max and Step of the row |
| <kbd>Enter</kbd> (element symbol) | Commit the symbol and open a new row under it |
| <kbd>Ctrl+Space</kbd> (expression field) | Show every suggestion for the cursor position |
| <kbd>Up</kbd>, <kbd>Down</kbd>, <kbd>Tab</kbd>, <kbd>Esc</kbd> (suggestions) | Move through the list, accept the suggestion, close the list; <kbd>Enter</kbd> accepts once you have moved through the list |

Read-only fields (the balance element, a row being added) are skipped. Without <kbd>Ctrl</kbd>, <kbd>Left</kbd> and
<kbd>Right</kbd> always move the cursor inside the text.

## Help window

| Keys | Action |
|---|---|
| <kbd>F1</kbd>, <kbd>Alt+Home</kbd> | Documentation Home |
| <kbd>Alt+Left</kbd>, <kbd>Alt+Right</kbd> | Back, Forward (also the arrow buttons above the contents) |
| <kbd>Ctrl+F</kbd> | Move to the search field |
| <kbd>Enter</kbd> (search field) | Open the best match |
| <kbd>Esc</kbd> (search field) | Clear the search |
| Arrow keys (contents tree) | Move between topics; Right expands and Left collapses a section |
