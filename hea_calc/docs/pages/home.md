# Documentation Home

HEA Calculator evaluates multi-component alloy compositions with one shared calculation engine: physical,
thermodynamic and structural descriptors, and the predictions of eight published phase-formation models, M1–M8.
This documentation explains how to define compositions, run calculations, read and analyse the results, and how
each value is calculated.

## Start here

* [Your First Calculation](help://first-calculation) — calculate the equiatomic Cantor alloy CoCrFeMnNi step by
  step.
* [Composition Space](help://composition-space) — generate and calculate every composition of a set of element
  ranges.
* [Composition Expressions](help://composition-expressions) — calculate formulas such as AlxCoCrFeNi for a range of
  x.
* [Results Table](help://results-table) — sort, filter, inspect and export results.
* [Prediction Model Coverage](help://model-coverage) — which data each model needs, and why a model can be N/A.

## Help inside the application

* **F1**, the **Help** icon at the right of the header, and **File › Help** open this documentation.
* An information icon next to a label opens a short explanation (a toggletip); its links lead to the matching
  topic here.
* The **Options** menus of the Analysis panel open [Prediction Model Coverage](help://model-coverage) and
  [Collection Analysis](help://collection-analysis).

> **Results are temporary.** Results are stored in a temporary database that is deleted when you close HEA
> Calculator. Export the results you want to keep — see [Exporting Results](help://export).
