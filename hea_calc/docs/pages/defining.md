# 3. Defining Alloy Compositions

Composition setup has three modes, chosen with the switcher at the top right of the panel; the panel title names the
active mode. Compositions can also be imported from a spreadsheet. All of them send plain compositions to the same
calculation engine.

| Mode | Use it to |
|---|---|
| **Single composition** | calculate one composition |
| **Composition space** | calculate every composition of a set of element ranges |
| **Composition expression** | calculate compositions written as formulas, with optional variables |
