## Original software

HEA Calculator is derived from HEACalculator, the open-source program created by Doğuhan Sarıtürk
([github.com/dogusariturk/HEACalculator](https://github.com/dogusariturk/HEACalculator); cite as
[https://doi.org/10.5281/zenodo.3590318](https://doi.org/10.5281/zenodo.3590318)). The calculations of this version were
reimplemented from the publications above and validated against their published values.
