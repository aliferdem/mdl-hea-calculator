# Welcome to HEA Calculator

Select elements, define one composition or a whole set of compositions, and calculate. Each result lists its
descriptors and one prediction per model; results stay in the results table for this session, where you can sort,
filter, analyse and export them.

![The main window after calculating CoCrFeMnNi: Element selection, Composition setup and Analysis above the results table.](images/main-window.png)

## Quick start

1. **Select elements.** Click elements in the periodic table of **Element selection**. Hover an element to see its
   properties and which models have data for it.
2. **Define the composition.** In **Composition setup**, choose a mode with the switcher at the top right —
   **Single composition**, **Composition space** or **Composition expression** — and enter amounts, ranges or an
   expression.
3. **Calculate.** Select **Calculate** at the bottom right of Composition setup. A batch shows its progress in the
   header.
4. **Inspect the results.** Each composition becomes a row with its descriptors and one prediction tag per model.
   Double-click a row to examine it in **Analysis**.
5. **Analyse or export.** Switch Analysis to **Collection** to study a whole calculation run, or use **Export** above
   the results table to save the results as an Excel workbook or a CSV file.

> **Results are temporary.** Results are stored in a temporary database that is deleted when you close HEA
> Calculator. Export the results you want to keep.
