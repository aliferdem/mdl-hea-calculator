# Navigating the Documentation

The documentation opens in its own window, so it can stay open beside the calculator. Topics are arranged in a
tree of numbered sections; every page has a breadcrumb, previous and next links, and related topics.

## Parts of the Help window

| Part | Use |
|---|---|
| **Home** (house icon, top left) | Returns to Documentation Home. |
| **Search documentation** | Searches every page. Results replace the article; select a result to open it. |
| Contents tree (left) | Every section and page. Select a section to read its overview; the chevron expands or collapses it. The current page is marked. |
| Breadcrumb (above the title) | The sections that contain the current page. Select one to go up. |
| **Previous** / **Next** (end of each page) | The neighbouring pages in reading order. |
| **Related topics** | Pages that continue the current topic. |

## Searching

Type at least one word. The search looks at page titles, headings and text, and ranks title and heading matches
first. Several words must all occur in the same section. Search understands common spellings of symbols and
quantities:

| You type | Also finds |
|---|---|
| delta | δ, size mismatch |
| delta CN12 | δ<sub>CN12</sub>, Kittel radii |
| mixing enthalpy | ΔH<sub>mix</sub> |
| mixing entropy | ΔS<sub>mix</sub> |
| atomic percent | at.% |
| weight percent | wt.% |
| omega, gamma, lambda, phi | Ω, γ, Λ, φ |
| VEC | valence electron concentration |

When you open a page from the search results, the words you searched for are highlighted. Press **Esc** in the
search field to clear it and return to the page you were reading.

## Keyboard

| Keys | Action |
|---|---|
| <kbd>F1</kbd> | Open Documentation Home (from the main window or the Help window) |
| <kbd>Ctrl+F</kbd> | Move to the search field |
| <kbd>Enter</kbd> (in the search field) | Open the best match |
| <kbd>Esc</kbd> (in the search field) | Clear the search |
| <kbd>Alt+Home</kbd> | Documentation Home |
| Arrow keys (in the contents tree) | Move between topics; Right expands and Left collapses a section |
