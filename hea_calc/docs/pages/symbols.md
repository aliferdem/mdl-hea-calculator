Every descriptor the calculator reports, with its symbol, unit and definition. The same names appear in the results
table headings, the Analysis panel, plots and exported files. c<sub>i</sub> is the atomic fraction of element i.

## Two size mismatches

δ and δ<sub>CN12</sub> use the same equation with different radius sets and are labelled **Size mismatch — Guo &
Liu radii** and **Size mismatch — Kittel CN12 radii** wherever both can appear. Compare each only with the model that
uses it: δ for M2, M4 and M5 (and the radii of M3), δ<sub>CN12</sub> for M1.

## Units

| Unit | Meaning |
|---|---|
| at.% | atomic percent |
| wt.% | weight percent |
| g cm⁻³ | density |
| K | kelvin |
| kJ mol⁻¹ | kilojoule per mole of atoms |
| J mol⁻¹ K⁻¹ | joule per mole of atoms and kelvin |
| meV atom⁻¹ | millielectronvolt per atom (1 meV atom⁻¹ = 0.0964853 kJ mol⁻¹) |
| % (δ) | size mismatch as a percentage of the mean radius |
| — | dimensionless |

## Composition terms

| Term | Meaning |
|---|---|
| Element family | The set of elements present, written alphabetically: Al-Co-Cr-Fe-Ni. |
| System size N | The number of elements in a composition. |
| Calculation run | All results of one calculation (a single composition, a composition space, a set of expressions or an import). |
| Design coordinates | The range values or expression variables that generated a result. |
